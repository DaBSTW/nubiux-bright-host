# Nubiux Launchpad

Quiero que actúes como un diseñador UX/UI senior, experto en conversión (CRO), branding, marketing y desarrollo web moderno. Tu objetivo es crear una landing page premium para una empresa de hosting llamada Nubiux, con un diseño de nivel profesional similar a empresas como Hostinger, SiteGround o Namecheap.



# Objetivo



Crear una landing diseñada para convertir visitantes en clientes, transmitiendo confianza, velocidad, seguridad y profesionalismo.



La web debe ser completamente responsive (móvil, tablet y escritorio), extremadamente rápida y con un diseño moderno utilizando animaciones suaves, tarjetas elegantes, iconografía profesional, mucho espacio en blanco y microinteracciones.

## Identidad visual



Quiero una identidad visual limpia, minimalista y premium, inspirada en empresas como Stripe, DigitalOcean, Vercel y Dropbox.



La página debe transmitir confianza, profesionalismo y tecnología, evitando por completo una apariencia oscura.



### Paleta de colores



• Color principal:

Blanco (#FFFFFF)



• Color secundario:

Azul (#2563EB)



• Color de apoyo:

Azul claro (#60A5FA)



• Fondos alternativos:

Gris muy claro (#F8FAFC)



• Texto principal:

Gris oscuro (#1E293B)



• Texto secundario:

Gris medio (#64748B)



El blanco debe dominar toda la interfaz.



El azul debe utilizarse únicamente para:



- Botones

- Enlaces

- Iconos

- Tarjetas destacadas

- Elementos interactivos

- Badges

- Detalles decorativos



No utilices colores negros, morados ni degradados intensos.



Si utilizas degradados, deben ser muy sutiles entre blanco y azul claro.



Toda la página debe sentirse luminosa, moderna, elegante, limpia y profesional.
